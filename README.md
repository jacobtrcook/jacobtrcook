## Featured project

**[Predicting Freight Shipping Costs in Global Health Supply Chains](https://github.com/jacobtrcook/supply-chain-freight-cost-prediction)**

Gradient boosting model predicting per-shipment freight cost for international health-commodity
deliveries (HIV/ARV, malaria diagnostics) shipped to 43 developing countries between 2006 and
2015. Reaches **R² = 0.756** on held-out shipments, roughly double a ridge-regression baseline.
Used as a screening tool, the top 50 shipments it flags as priced above expectation account for
**$2.2M** in freight, a dollar-weighted worklist for contract review instead of a random audit
sample.
